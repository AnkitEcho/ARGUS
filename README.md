# AI-Based Target Hitting Robotic Bot with Vision Tracking

## Project Objective

Develop an autonomous robotic system capable of detecting,
tracking, and hitting moving targets using computer vision
and AI.

## Project Goals

- Detect targets using computer vision
- Track moving targets
- Predict target movement
- Control the robot to aim and hit targets
- Explore behavioural patterns in target movement
